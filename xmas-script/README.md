# 圣诞庆祝聚会 · 四人主持稿

由 `E:\1225.md` 生成的单文件 HTML 主持稿，包含开幕词与闭幕词各 9 段（含两段「四位主持人合」）。可直接在线阅读、现场提词或打印成 A4 稿件。

## 现场功能

- 四位主持人以四种颜色区分，两段合诵单独排版
- 点击黄色的 `（姓名）` 可填写主持人姓名，自动保存于浏览器本地
- 每段右侧圆圈可标记「已念」，顶部进度条与章节计数实时更新
- 「只看 甲/乙/丙/丁」用于单人排练
- 深色大字「提词模式」，适合手机或投屏
- 字号调节、复制全文、A4 打印（打印时自动恢复全部台词、隐藏已念标记）
- 快捷键：`+` / `−` 字号，`1` / `2` 跳转章节，`T` 提词，`P` 打印，`C` 复制，`Esc` 退出

## 本地使用

直接用浏览器打开 `index.html` 即可，无需构建、无运行时依赖。字体使用 Google Fonts，离线时自动回退到系统衬线/无衬线字体。
